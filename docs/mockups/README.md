# Mockups

Sketches from the design session, drawn at the real 466 px display size. They show intent, not pixel-exact firmware output.

- `pie.png`: `pie` without `center`, clock in the small hole.
- `pie-center.png`: `pie` with a `center` Item and a running countdown; curved labels on the quarters.
- `single.png`: `single` page.
- `single-countdown.png`: `single` with value and countdown ring.
- `icons.png`: the compiled-in icon list.
- `klima-thermostat.png`: Dial as climate page, states Kühlen, Heizen and Aus.
